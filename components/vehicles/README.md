# Openbare voertuiggalerij

VehicleGallery toont uitsluitend de foto-URLs uit de openbare voertuigprojectie, in de aangeleverde VVOS-volgorde. De eerste foto is de startfoto. Er worden geen extra gegevens opgehaald.

Bezoekers bladeren met pijlen, miniaturen, horizontaal vegen op de hoofdfoto of de pijltjestoetsen. Klikken op de hoofdfoto opent een native modaal dialoogvenster. Sluiten kan met de sluitknop of Escape; de focus keert terug naar de opener. Achtergrondscrollen is tijdelijk geblokkeerd. De galerij draait niet automatisch.

De hoofdweergave heeft verhouding 3:2, passend bij 1920x1280 foto’s. Afwijkende formaten blijven volledig zichtbaar zonder afsnijden. Miniaturen laden vertraagd. Bij één foto ontbreken bladerknoppen; zonder foto’s verschijnt een melding.

Controleer bij wijzigingen de eerste/laatste foto, miniaturen, vergroting, Escape, focusherstel, mobiel vegen en nul/één foto. Gebruik fictieve beelden voor tests.
